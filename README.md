# Stream Bot Manager

Telegram bot + embed server for live m3u8 streams.

## Bot commands
- `/stream <m3u8> <title>` – start a stream
- `/live` – dashboard with real-time preview, uptime, viewers, Stop/Embed buttons

## Features
- Clappr player (auto quality, PiP, live icon, viewer count)
- m3u8 proxy (bypasses CORS / domain locks)
- Real-time screenshots & health check
- Runs 24/7 on VPS with PM2
